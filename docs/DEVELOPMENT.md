# 開發、測試與章節維護

玩家操作說明請閱讀根目錄 README。本文件保留開發與驗證資訊。

## 開發用啟動

專案為純 HTML / CSS / JavaScript，沒有第三方執行期套件或後端。

```sh
python3 -m http.server 8000
```

開啟 http://localhost:8000 。`index.html` 使用 JavaScript modules，因此開發時需要 HTTP。玩家使用單檔離線版無須此步驟。

Node.js 22 以上可打包與測試，不需安裝套件：

```sh
npm run build
npm test
```

## 地震章節

新局的存檔為 version 3。`chapter.revision: 1` 啟用擴充章節；其他路線及從 version 2 遷移的存檔保留原本的簡短流程。沿用既有儲存鍵，避免更新後直接遺失舊存檔。

章節流程：

```text
平時準備／背包互動
→ 地震時就近掩護（禁止移動）
→ 搖晃停止、停電照明
→ 確認家人、操作收音機取得演練指引
→ 依現場確認的路線撤離
→ 安全步道／家庭聯絡點
→ 有約定直接確認；無約定到協助站詢問
→ 收容登記／個人用品與照護需求
→ 陪伴小晴／報平安／家庭小結
→ 五種主要結局與五項因果後日談
```

背包草稿、選定物品、收音機電源與頻道會儲存。即使玩家在回饋頁重新整理，也應能繼續轉場。新增轉場時請一併補上重整測試。

遊戲格數、亮光半徑、頻道分類與任務條件均為敘事規則，不是現實應變標準。不可將未確認安全的室內探索或返家取物寫成必要操作。

## 語言協助

沒有載入 Google 嵌入式翻譯腳本，也不呼叫付費翻譯 API。使用者選擇目標語言後，連結以 `https://translate.google.com/?sl=zh-TW&tl=...&text=...&op=translate` 開啟目前可見的對話文字。

只有主動點外部連結才會連到 Google，無自動翻譯請求；不傳送整份存檔。這不是原生多語版，Canvas 地圖文字不會翻譯。若未來要提供完整離線英文版，應建立獨立字串表與經審訂的情境翻譯，包含地圖、狀態及動態選項。

## 驗證紀錄與發布前確認

自動測試涵蓋原五條簡短路線、新地震章節的完整準備／補救分支、條件選項、物件草稿、存檔遷移、轉場恢復、翻譯連結與單檔打包。這是模擬控制器驗證，不等同真實裝置驗收。

環境無法啟動本機 HTTP 預覽與 Chrome，尚未完成瀏覽器畫面、真實觸控、Google 翻譯服務、離線快取與新版線上部署的端對端驗收。

發布前請在桌面與手機確認：

- 放大地圖後，點地面與標記的座標正確；電腦方向鍵與手機搖桿拖曳、放手都正常。
- 背包可選取、取出、關閉接續，超過六格會提示。
- 沒帶手電筒可用手機或尋找備用品；沒帶照護用品不能選「拿出備好的用品」。
- 收音機關機或音樂頻道不會提供撤離指引。
- 有／無家庭約定都能完成章節，且出現不同後日談。
- 翻譯以新分頁顯示目前場景，返回原頁仍保留進度。
- 下載單檔可離線遊玩，已存在的 version 2 存檔仍能繼續。


## 軍事章節的狀態與回歸驗證

新建立的軍事局帶有 `chapter.kind: military`，沿用 version 3 儲存格式。舊軍事存檔的 `chapter: null` 仍保留簡短流程。新局固定儲存 `scenario`（stay／relocate）、`airAlert`、`encounter`（clear／blocked），載入時不重新抽選。

新增 `bunker` 與 `cover` 場景。兩者都禁止角色移動，以當前情境互動推進。事件選擇、路線開放與抵達檢查分開驗證，不能以抵達某座標取代前置條件。防空解除及街口通行指引之後才回復適當移動。

`militaryTask` 提供當前任務，`militaryDepartureReady`、`militaryArrivalReady` 檢查條件。每個改變場景的事件都需在 `restoreMilitaryTransition` 對應處理，涵蓋選完選項但尚未點「繼續」就重新整理的情況。

`restoreSavedState` 在使用存檔之前驗證路線、場景、數值、物品、頻道與事件索引；損壞存檔回到開始畫面。回顧中的存檔文字會跳脫 HTML，不能被當成標籤執行。

軍事測試包含六種路線、每次選擇後重整、96 組固定種子的不同準備與選項、單檔離線控制器、地圖互動點可達性、軍事活動區域碰撞、舊存檔、損壞資料與重複點擊。這些是模擬 DOM／Canvas 測試，不等同於瀏覽器與真實裝置驗收。測試者流程見 [TESTING.md](TESTING.md)。


## 手機透明搖桿

搖桿為地圖左下角的半透明 DOM 疊層，周圍容器不攔截地圖點擊。使用 Pointer Events 與 pointer capture 追蹤同一根手指，拖出圓盤時仍能收到移動及放開事件；僅搖桿區域以 `touch-action: none` 阻止瀏覽器捲動手勢。

15% 中央死區避免漂移，拖曳距離換算為 0–1 類比速度，斜向移動不加速。搖桿輸入沿用現有碰撞檢查；接手時取消自動尋路，持有搖桿時忽略其他手指對地圖的移動指令。

`pointerup`、`pointercancel`、`lostpointercapture`、視窗失焦、頁面隱藏、畫面尺寸改變與開啟對話都會清除輸入並回中。軍事防空、暫時掩蔽、對話中與遊戲結束後不接受搖桿移動。

`tests/joystick.test.js` 覆蓋速度、死區、斜向、拖出範圍、多指、中斷、鍵盤接手、點擊行走、碰撞與單檔離線版。原方向按鈕已移除；真機的拇指手感、透明度與遮擋仍需人工驗收。
