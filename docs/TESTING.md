# 測試者指南：軍事章節

本文件提供可重現的操作與預期結果。所有地圖、軍事活動與警報為虛構，不要以遊戲替代真實警報與現場指示。

## 測試前

1. 記錄網頁網址、使用裝置、作業系統與瀏覽器版本。
2. 確認部署已更新；開始畫面應有「軍事章節 · 斷訊之後，仍有彼此」。
3. 按「重新開始」再選軍事章節，避免接續舊版的簡短存檔。
4. 請分別用鍵盤、滑鼠、手機觸控，以及單檔離線版測試。

## 六條可重現路線

在軍事章節的路線選單指定以下條件，隨機模式也可能抽到相同情況。

| 路線代碼 | 選單 | 主要預期 |
| --- | --- | --- |
| M-S-N | 安全住家 · 持續確認資訊 | 不外出，確認用品、家人需求與可靠資訊 |
| M-S-A | 安全住家 · 途中收到防空警報 | 先防空避難，解除並確認指示後，回到住家安頓 |
| M-R-N-C | 依指引撤離 · 可安全避開街口 | 遇到疑似軍事活動，依已確認路線遠離 |
| M-R-N-B | 依指引撤離 · 暫時無法通行 | 先進安全掩蔽場景，得到可信通行指引後繼續 |
| M-R-A-C | 依指引撤離 · 防空警報與可通行步道 | 先防空避難，解除後再處理街頭事件 |
| M-R-A-B | 依指引撤離 · 防空警報與暫時掩蔽 | 依序完成防空、暫時掩蔽、確認通行、救濟站安置 |

代碼只表示演練路線，不是實際區域或警報編號。

## 每條路線至少測兩次

**完整準備**：背包選飲水、乾糧、手電筒、個人用品、紙本資料與收音機；完成居家儲備、家庭約定與查證。觀察物品條件與後日談。

**不完整準備**：背包留空或只放小熊、不做聯絡約定、略過儲備。應仍能透過協助完成，不得卡在無法選的選項。未準備的物品不能憑空取出。

也請選擇錯誤選項：應顯示解析並補救，記錄選擇，能繼續到結局；不描繪傷亡。

## 容易出問題的位置

| 操作 | 應看到的結果 |
| --- | --- |
| 還沒確認家人、群組與廣播，就按「確認留或走」 | 提示當前任務，不直接外出 |
| 收音機未開電源或停在音樂頻道 | 無法取得本次指引 |
| 防空警報期間按方向鍵、拖曳透明搖桿或點地面 | 角色不四處走動；E、互動按鈕或情境標記可繼續 |
| 沒完成姿勢與等候情境，就點解除指引 | 提示前置任務，不跳過 |
| 暫時掩蔽時嘗試走到街上 | 角色留在掩蔽處，確認可信通行指引後才回街區 |
| 走向軍事活動標示區、封鎖區或建物 | 無法穿越；自動尋路應繞行 |
| 未確認路線或爸爸下落，就直接點救濟站 | 提示要先處理的任務 |
| 留在住家分支前往「簡短報平安」 | 能走近並觸發，不被家具擋住 |
| 連續快速點同一個選項或整理背包的完成鈕 | 不重複加分、重複記錄或打亂轉場 |
| 完成後開回顧、分享與重新開始 | 內容正確；新局取代單局存檔 |

## 重整、切換與離線

- 在**選完選項、還沒按繼續**時重整，特別測防空進入／解除、街頭遭遇、暫時掩蔽離開、救濟站登記與最後小結。
- 整理背包到一半關閉對話再回來，草稿應保留。
- 切換到其他分頁或鎖定手機再回來，方向鍵與搖桿不應持續卡住。
- 保留舊版軍事／地震存檔更新網站，應能續玩；重新開始才使用新版章節。
- 下載單檔版，斷網後完整走一次。Google 翻譯與官方連結需要網路，遊戲本身不應依賴它們。
- 網頁版需首次完成快取後再測離線重開，與單檔版分開記錄結果。

## 語言與畫面

- 每個對話都能選語言並開啟 Google 翻譯；回原分頁後進度不變。
- 確認翻譯的是目前對話，而非前一個事件。地圖 Canvas 標籤不會自動翻譯。
- 手機直向、橫向、地圖放大／總覽都要測；點擊標記的座標應正確。
- 小螢幕長對話可捲動，選項、繼續與語言入口都能操作。

## 回報格式

```text
路線代碼：
裝置／系統／瀏覽器：
網頁版或離線版：
目前任務：
重現步驟（包含背包與家庭約定）：
預期結果：
實際結果：
能否重現：每次／偶爾
截圖或錄影：
```

若開發者需要更細的記錄，可提供遊戲行動簿中的最後幾個事件。請勿附上真實身分證、密碼、軍事位置或其他個資。

## 手機搖桿驗收

- 地圖下方的獨立操作區應出現半透明圓盤與搖桿頭，不再顯示四個方向按鈕。
- 在中央輕觸不應漂移；小幅推動慢走，推到外側正常速度；斜向不比直走快。
- 手指拖出圓盤後仍可控制，放手立即停止並回中；第二根手指不應接管或釋放第一根手指。
- 開啟對話、切換分頁、鎖定手機、旋轉畫面後，不應繼續移動。
- 地圖仍能點擊行走；開始拖搖桿會取消原本自動尋路。按軍事掩蔽場景的互動鈕仍可繼續，搖桿則停用。
- 分別測試 Safari／Chrome、直向／橫向與停電照明場景的可見性，確認搖桿與手指不遮住地圖、橫向與直向皆不重疊；可用附近互動按鈕觸發事件。
