# 今天，也要一起平安

**走進熟悉的日常，練習不熟悉的時刻。**

給一般民眾與家人的 2D 互動安全情境遊戲。走動、探索、和家人說話，在每一次選擇裡練習照顧自己與彼此。

## 第一次玩，從哪裡開始？

建議先選首頁的 **「地震示範章節 · 燈熄了，約定還亮著」**。

你和小晴、阿嬤待在家裡，爸爸出門到里辦公處辦事。從平時的一個背包、一張聯絡卡開始，直到停電後重新確認彼此的下一步。可以慢慢讀、自由探索，沒有操作倒數。

也可以選「隨機開始」或展開「指定情境練習」，體驗地震、防空、海嘯、颱風、軍事侵略與資安六種情境。

## 移動與互動

| 裝置 | 移動 | 互動 |
| --- | --- | --- |
| 電腦鍵盤 | 方向鍵或 WASD | 靠近標記，按 E 或空白鍵 |
| 滑鼠 | 點可通行的地面 | 點物件標記，角色會走近並互動 |
| 手機／平板 | 拖曳地圖下方的透明搖桿，或點地面 | 點互動標記，或使用「與附近物件互動」按鈕 |

- 畫面上方的 **目前任務** 會告訴你下一步，也可以自行探索其他物件。
- 搖桿位於地圖下方的獨立操作區，不覆蓋地圖。手機搖桿可往任意方向拖曳，推得愈遠走得愈快；放手立即停止。拖出圓盤仍會追蹤手指，切換分頁、開啟對話或旋轉裝置會歸零。防空與暫時掩蔽期間停用移動。
- **放大地圖／地圖總覽** 可切換觀看範圍，放大時畫面會跟著角色移動。
- **平安行動簿** 記錄物品、家人狀況與已經做過的選擇。
- 對話中的知識依據連結，可以帶你閱讀官方說明。

## 地震章節裡，你可以做什麼？

### 親手整理背包

點選物品裝入，再點一次可取出。背包有六個**遊戲格數**，讓你練習取捨；這不是現實的重量標準，也不是完整防災清單。實際準備仍應依家人需求與負重能力調整。

手電筒、紙本資料、收音機、阿嬤的個人用品與小晴的小熊，可能在不同時刻派上用場。裝好後，這次選擇就會保留到後續劇情。

### 停電後，先照亮眼前

地震搖晃時會暫停移動，先思考就近掩護。搖晃停止後才開放後續探索。

有帶手電筒，可以立即取用；沒帶，也能暫用手機或查看家中備用櫃。光線會隨角色移動，手機與手電筒的照明範圍也不同。

### 聽見可靠的下一步

走近收音機、打開電源，再選擇演練防災廣播。這是一個簡化的操作介面，不是真實頻率、即時廣播或災情。

### 讓家人一起參與

小晴可以幫忙記住約定與標示，阿嬤會表達照護需求。爸爸暫時聯絡不上時，事先的家庭約定與現場協助，會讓故事走向不同路徑。

### 看看每個人的後日談

完成安頓、報平安與家庭小結後，會得到一個主要結局，以及照明、爸爸、阿嬤、小晴與鄰里的個別後日談。地震與軍事章節各有五種主要結局，其餘情境保留四種練習結局。

沒有必要追求一次「全對」。回顧會說明哪些準備派上用場、哪些協助接住了你們，以及下次可以一起完成的一件事。

## 軍事章節：斷訊之後，仍有彼此

首頁選擇 **「軍事章節 · 斷訊之後，仍有彼此」**，可選一條練習路線，或隨機開始。

- **留在安全住家**：沒有撤離指示、住家仍可安全停留時，先確認資訊、用品與家人需求。
- **依指引撤離**：住家不宜停留、現場確認路線後，依安排前往救濟站。
- **出現防空警報**：先到合適防空空間避難，等可靠解除訊息，再確認後續指示。警報中不會讓角色四處走動；按 **E**、互動按鈕或情境標記繼續。
- **街口遇到疑似軍事活動**：有確認可通行的路線就遠離；暫時無法離開時先掩蔽，等可信的通行指引。不要靠近辨識、圍觀或拍攝上傳軍事動態。
- **斷訊、假消息與物資**：不依投降假消息或陌生 QR code 行動，使用可靠資訊管道，依官方安排取得救濟或配售協助。

章節有五種主要結局與六項後日談。實際能否留或走，取決於本次劇情給出的條件；不把軍事危機一律寫成外出撤離，也不將救濟站當成防空掩蔽的替代品。

畫面中的 `M-S-A` 等代碼代表本次練習路線，可在回報問題時附上，方便測試者重現。所有地點、警報、通行資訊與人物均為虛構，不是即時災情或真實導航。

## 語言與 Google 翻譯

遊戲原文是 **繁體中文**。每個對話上方提供 **Language / 語言** 選單：

1. 選擇 **English**、日本語、한국어、Tiếng Việt、Bahasa Indonesia、ไทย或 Español。
2. 點擊 **Google Translate · read this scene**。
3. 在新分頁閱讀目前情境與選項的機器翻譯，再回原分頁繼續遊戲。
4. 若需要其他語言，選 **Other languages**，並在 Google 翻譯頁切換目標語言。

這是**目前對話的外部翻譯入口**，不是完整的原生多語版本，也不會自動翻譯地圖上的 Canvas 文字。翻譯需連網；離線時可繼續使用繁中原文。只有主動開啟連結才會把目前這段文字提供給 Google，不會傳送完整存檔。機器翻譯可能有誤，安全知識仍以官方原始資料為準。

## 離線遊玩與存檔

| 方式 | 如何使用 |
| --- | --- |
| 網頁版 | 第一次連網載入、完成離線快取後，可在同一瀏覽器離線開啟；官方資料與 Google 翻譯仍需網路 |
| 單檔版 | 在 GitHub 開啟 `一起平安-離線版.html`，使用 **Download raw file** 下載，再用桌面瀏覽器開啟 |

一般玩家不必安裝套件、Node.js、登入帳號或架設伺服器。手機直接開啟 HTML 檔的支援依系統而異，建議用網頁版。

遊戲會嘗試在目前瀏覽器自動儲存進度，包括背包未完成的整理與收音機設定。關掉再開可以接續；選擇新的一局會取代原存檔。不同裝置、瀏覽器或網頁版與本機檔案之間不會同步，清除網站資料也可能清除存檔。

從舊版接續的地震或軍事存檔會保留原來的路線；要體驗完整新版，請按 **重新開始**，再選相應章節。

## 六種情境，有不同的行動方式

| 主要情境 | 練習重點 |
| --- | --- |
| 地震與停電 | 就近掩護、搖晃停止後評估行動、照明、聯絡與家庭合作 |
| 防空避難 | 合適的掩蔽空間、現場引導與警報解除指示 |
| 海嘯警報 | 遠離海岸、往高處避難、不任意返回 |
| 颱風來臨 | 提早準備，依住家狀況與警戒、撤離指示行動 |
| 軍事侵略與斷訊 | 遠離軍事活動，透過可靠管道獲取資訊與安排 |
| 資安與可疑訊息 | 可疑連結、帳號與個資保護、資訊查證 |

目前有 52 個選擇事件，加上背包與收音機互動；一局只會遇到其中一部分。防空地下空間、海嘯高處與災後收容／救濟地點不會混用。錯誤選擇提供解析與補救，不描繪傷亡。

## 一起玩的小建議

- 和家人輪流做決定，聊聊「如果是我們家，會需要什麼？」
- 玩完後挑一件可以實際完成的小事：檢查照明、整理聯絡卡，或確認附近避難設施。
- 教師或活動帶領者可暫停討論，再繼續劇情，不必以遊戲分數評定個人的真實應變能力。

## English quick guide

**Together, Safe** is a browser-based 2D safety learning game for families. Start with the featured earthquake or civilian military-crisis chapter, or choose a random practice scenario.

- Move with the arrow keys or WASD. Press E or Space near a marker to interact.
- On touch devices, drag the translucent joystick below the map, or tap the ground or a marker. Release the joystick to stop.
- Follow the current task above the map. There is no reaction countdown.
- Choose **English** in the language selector above each dialogue, then open **Google Translate** to read the current scene and choices in a new tab. Return to the original tab to play.
- For more languages, choose **Other languages** and change the target language in Google Translate.

The game is authored in Traditional Chinese. Translation assistance requires internet access and is not a native English localization; map labels remain in Chinese. The downloadable HTML runs offline in a supported desktop browser. Progress is stored locally when browser storage is available.

This independent educational game uses fictional places and events. It does not provide live warnings, real navigation, or a guarantee of safety. Follow local official alerts and on-site instructions in real emergencies.
