# 今天，也要一起平安

**走進熟悉的日常，練習不熟悉的時刻。**

一款給一般民眾與家人的 2D 互動安全情境遊戲。玩家自由移動、探索環境，透過準備、查證與互助做出選擇，走向不同結局。希望每一次遊玩，都能讓你找到一件可以帶回生活的小小準備。

知識依據為國防部「臺灣全民安全指引」官方網站，故事、地圖、美術與遊戲規則皆為獨立原創設計。本專案為非官方教育作品。

> 目前為可供試玩的初版，尚未發布公開網址。完成 GitHub Pages 部署後，可將實際遊戲網址加入這裡。

## 開始遊玩

| 方式 | 如何開始 | 網路需求 |
| --- | --- | --- |
| 網頁版 | 發布後，點擊 GitHub Pages 遊戲網址 | 首次載入需要網路；完成快取後可離線遊玩 |
| 單檔離線版 | 下載 [`一起平安-離線版.html`](一起平安-離線版.html)，用桌面瀏覽器開啟 | 遊戲本身不需網路 |

下載離線版時，請在 GitHub 檔案頁使用 **Download raw file**，將完整 HTML 儲存到電腦。一般玩家不需要安裝套件、Node.js 或啟動本機伺服器。

手機建議使用網頁版。手機系統對從檔案管理器開啟 HTML 的支援不同；官方資料連結仍需網路。

## 怎麼玩？

1. 選擇「隨機開始」，或展開「指定情境練習」。
2. 在家裡探索物資、家庭約定與訊息，靠近標記互動。
3. 到玄關開始危機情境，依當次指示選擇行動與目的地。
4. 安頓家人、報平安，查看結局與自己的選擇回顧。

| 裝置 | 操作 |
| --- | --- |
| 電腦 | 方向鍵或 WASD 移動，E 或空白鍵互動 |
| 滑鼠 | 點地面行走，點互動標記走近並觸發事件 |
| 手機／平板 | 點地面、點互動標記，或長按畫面下方方向鍵 |

沒有反應倒數，可以停下來思考。遊戲會嘗試在目前瀏覽器儲存單局進度；選擇新路線後會取代舊存檔。本機檔案的存檔能否保留，依瀏覽器設定而定。

## 你可能遇到的情境

| 主要情境 | 練習重點 |
| --- | --- |
| 地震與停電 | 就近掩護、搖晃停止後評估行動、照明與備援資訊 |
| 防空避難 | 辨識警報、選擇合適避難空間、等待解除指示 |
| 海嘯警報 | 遠離海岸、往高處避難、不任意返回 |
| 颱風來臨 | 提早準備、留意警戒，依住家狀況與撤離指示行動 |
| 軍事侵略與斷訊 | 避開軍事活動、取得可靠資訊、依引導尋求安置 |
| 資安與可疑訊息 | 辨識可疑連結、保護帳號與個資、資訊查證 |

每局抽取一個主要情境，搭配兩個日常支線，也可以自行指定路線。目前共 **25 個情境事件、四種結局**；單局只會遇到其中一部分。

不同危機使用不同規則與目的地。地震搖晃時不要求玩家奔跑找出口；海嘯高處、防空避難空間與災後收容／救濟地點分別判定。錯誤選擇會提供解析與補救，不描繪傷亡。

## 這個專案的特色

- 自由移動、探索場景、互動選擇與分歧結局。
- 免登入，遊戲運算與存檔在玩家瀏覽器中進行。
- 不串接 AI API、不需要後端，不使用遊戲內追蹤或分析工具。
- 同時提供靜態網頁版與單一 HTML 離線版。
- 選擇回顧附官方依據，方便延伸閱讀與家庭討論。

## 發布自己的遊戲網址

專案已內附 GitHub Pages 工作流程。建立公開 repository、上傳檔案，再於 **Settings → Pages → Source** 選擇 **GitHub Actions** 即可依工作流程部署。

請參閱 [GitHub 建立儲存庫與發布教學](docs/DEPLOYMENT.md)，包含網頁上傳、終端機操作與常見問題。

## 開發與修改

使用純 HTML、CSS 與 JavaScript，沒有第三方執行期套件。

開啟開發用網頁：

```sh
python3 -m http.server 8000
```

接著開啟 <http://localhost:8000>。開發用的 `index.html` 使用 JavaScript modules，需要透過 HTTP 載入；單檔離線版可以直接開啟。

若要重新產生離線版或執行測試，需 Node.js 22 以上，不需 `npm install`：

```sh
npm run build
npm test
```

| 檔案 | 用途 |
| --- | --- |
| `content.js` | 情境、來源、路線、抽選與結局規則 |
| `game.js` | 場景、移動、互動、介面與存檔 |
| `style.css` | 響應式畫面樣式 |
| `scripts/build-standalone.mjs` | 將遊戲打包成單一 HTML |
| `sw.js` | 網頁版離線快取 |
| `tests/` | 邏輯、控制器流程與單檔打包測試 |
| `.github/workflows/pages.yml` | GitHub Pages 自動測試與部署 |

修改原始碼後請重新執行 `npm run build`；更新公開資產時也應更新 `sw.js` 快取版本。直接修改產出的離線 HTML，會在下次打包時被覆蓋。

## 目前驗證與限制

目前 **19 項自動測試通過**，涵蓋六條路線的模擬操作流程、尋路、錯誤入口、結局、轉場存檔恢復及單檔打包。這些測試不等於真實裝置驗收；瀏覽器畫面、手機觸控、離線快取與線上部署仍待實際確認。

- 地圖、警報、角色與事件為虛構情境，不提供真實導航或即時災情。
- 分數與結局是教學回饋，不代表實際安全程度或安全保證。
- 實際應對請依所在地官方警報、環境條件與現場人員指示。
- 存檔無法跨裝置同步；目前尚無完整的螢幕閱讀器替代遊玩模式。
